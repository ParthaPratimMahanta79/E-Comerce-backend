# 🛒 E-Commerce Backend API

A scalable and modular backend system for a full-stack e-commerce application, designed to handle product management, user authentication, order processing, and secure transactions.

---

## 🚀 Features

- 🔐 User Authentication & Authorization (JWT-based)
- 📦 Product Management (CRUD operations)
- 🛍️ Shopping Cart & Order Processing
- 💳 Payment Integration (optional/mock)
- 📊 RESTful API
- ⚡ Scalable architecture
- 🧾 Order history tracking

---

## 🏗️ Tech Stack

- Backend: Node.js, Express.js  
- Database: MongoDB (Mongoose)  
- Authentication: JWT  
- API Testing: Postman  
- Version Control: Git
